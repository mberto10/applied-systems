# Panel design foundation

Compounding Design neutral starter 0.2.0, copied unchanged from the installed Design skill's versioned template on 2026-10-03. CSS-only foundation; no runtime or brand substitution. Applied once to the dedicated panel, separately from the unchanged inline-card styling.

The panel uses `cd-system`, native fields/buttons/disclosures, typography roles and semantic tokens. Application-specific outline composition is namespaced `cd-custom-*`. Hierarchy uses native `details`/`summary` and separate inspect buttons; Tab, Enter and Space use native behavior, rather than claiming an ARIA tree widget.
